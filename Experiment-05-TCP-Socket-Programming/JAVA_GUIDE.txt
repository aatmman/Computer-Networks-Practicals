4. LEARNING OBJECTIVES
--------------------------------------------------------------------------------
- Master the TCP client-server paradigm in Java using object-oriented networking abstractions:
  * Server: `ServerSocket serverSocket = new ServerSocket(port)` -> `Socket client = serverSocket.accept()` -> Streams -> `close()`.
  * Client: `Socket socket = new Socket(host, port)` -> Streams -> `close()`.

- Handle networking exceptions, try-with-resources automatic closing, and graceful socket termination.

5. THEORY AND IMPORTANT TERMINOLOGY
--------------------------------------------------------------------------------
- Transmission Control Protocol (TCP): A connection-oriented, reliable transport protocol (Layer 4) providing full-duplex byte-stream delivery between two network endpoints.
- Socket Abstraction in Java:
  * `ServerSocket`: Implements a server socket that listens on a specified port and accepts incoming client connection requests via the blocking call `accept()`.
  * `Socket`: Implements the client socket endpoint (or the connected socket returned by `accept()`), providing input/output streams for data transfer.
- Java I/O Streams:
  * Character Streams: `BufferedReader`, `InputStreamReader`, and `PrintWriter` handle text-based messages with explicit character encodings (e.g., `StandardCharsets.UTF_8`).
  * Byte Streams: `InputStream` and `OutputStream` (`FileInputStream`, `FileOutputStream`) handle raw binary byte streams, essential for binary-safe file transfers.
- Three-Way Handshake: Automatically performed by the underlying OS TCP stack when `new Socket(host, port)` is invoked.
- Try-With-Resources: Java construct (`try (Socket s = ...)`) that ensures sockets and streams are closed automatically upon block completion, even if exceptions occur.

6. WORKING PRINCIPLE / ALGORITHM
--------------------------------------------------------------------------------
Task (a) - Say Hello:
1. Server creates `ServerSocket(9001)` and waits in `accept()`.
2. Client creates `Socket("127.0.0.1", 9001)` and sends greeting string.
3. Server reads greeting, logs client address, and returns reply greeting.
4. Client prints server's reply and both close their connections.

Task (b) - File Transfer:
1. Server creates `ServerSocket(9002)` and waits in `accept()`.
2. Client connects, opens file via `FileInputStream`.
3. Client reads raw bytes into buffer (4096 bytes) and writes to socket `OutputStream` until EOF (-1).
4. Server reads raw bytes from socket `InputStream` and writes directly to `FileOutputStream("received_file.dat")`.
5. Upon client closure, server read returns -1, closing the destination file cleanly.

Task (c) - Remote Calculator:
1. Server creates `ServerSocket(9003)` and waits in `accept()`.
2. Client reads arithmetic expression from user (e.g. `15 * 6`), sends line to server.
3. Server receives string, tokenizes operands and operator, evaluates result (handling division by zero), and replies with result or error string.
4. Client prints the computed response.

```
                |                                                |

             close()  <=========== FIN / ACK ===========>     close()
```

--- File 1: HelloServer.java (Port 9001) ---
```java
import java.io.*;
import java.net.*;
import java.nio.charset.StandardCharsets;

public class HelloServer {
    public static final int PORT = 9001;

    public static void main(String[] args) {
        System.out.println("========================================================");
        System.out.println("  TCP HELLO SERVER LISTENING ON PORT " + PORT + " (JAVA)");
        System.out.println("========================================================");
        System.out.println("Waiting for incoming client connection...");

        try (ServerSocket serverSocket = new ServerSocket(PORT)) {
            try (Socket clientSocket = serverSocket.accept()) {
                System.out.println("Client connected from " + clientSocket.getRemoteSocketAddress());

                BufferedReader in = new BufferedReader(
                    new InputStreamReader(clientSocket.getInputStream(), StandardCharsets.UTF_8));
                PrintWriter out = new PrintWriter(
                    new OutputStreamWriter(clientSocket.getOutputStream(), StandardCharsets.UTF_8), true);

                String clientMessage = in.readLine();
                System.out.println("Client says: \"" + clientMessage + "\"");

                String reply = "Hello from TCP Server! Connection verified.";
                out.println(reply);
                System.out.println("Sent reply: \"" + reply + "\"");
            }
            System.out.println("Server closed connection gracefully.");
        } catch (IOException e) {
            System.err.println("Server error: " + e.getMessage());
        }
    }
}
```

--- File 3: FileServer.java (Port 9002) ---
```java
import java.io.*;
import java.net.*;

public class FileServer {
    public static final int PORT = 9002;
    public static final int BUFFER_SIZE = 4096;

    public static void main(String[] args) {
        System.out.println("========================================================");
        System.out.println("  TCP FILE SERVER LISTENING ON PORT " + PORT + " (JAVA)");
        System.out.println("========================================================");
        System.out.println("Waiting for file upload from client...");

        try (ServerSocket serverSocket = new ServerSocket(PORT)) {
            try (Socket clientSocket = serverSocket.accept()) {
                System.out.println("Client connected from " + clientSocket.getRemoteSocketAddress());

                String outputFileName = "received_file.dat";
                try (InputStream in = clientSocket.getInputStream();
                     FileOutputStream fileOut = new FileOutputStream(outputFileName)) {

                    byte[] buffer = new byte[BUFFER_SIZE];
                    int bytesRead;
                    long totalBytes = 0;

                    System.out.println("Receiving file stream...");
                    while ((bytesRead = in.read(buffer)) != -1) {
                        fileOut.write(buffer, 0, bytesRead);
                        totalBytes += bytesRead;
                    }

                    System.out.println("File reception complete! Saved as \"" + outputFileName + "\" (" + totalBytes + " bytes).");
                }
            }
        } catch (IOException e) {
            System.err.println("File server error: " + e.getMessage());
        }
    }
}
```

--- File 4: FileClient.java (Port 9002) ---
```java
import java.io.*;
import java.net.*;

public class FileClient {
    public static final int PORT = 9002;
    public static final int BUFFER_SIZE = 4096;

    public static void main(String[] args) {
        String fileName = args.length > 0 ? args[0] : "send_file.txt";
        String serverIP = args.length > 1 ? args[1] : "127.0.0.1";

        File file = new File(fileName);
        if (!file.exists()) {
            try (FileWriter writer = new FileWriter(file)) {
                writer.write("This is sample text transmitted over a reliable TCP socket in Java.\n");
                writer.write("TCP stream ensures all bytes are received in order without data loss.\n");
            } catch (IOException e) {
                System.err.println("Could not create sample file: " + e.getMessage());
            }
            System.out.println("Created default sample file: \"" + fileName + "\"");
        }

        System.out.println("Connecting to TCP File Server at " + serverIP + ":" + PORT + "...");
        try (Socket socket = new Socket(serverIP, PORT)) {
            System.out.println("Connected! Sending file: \"" + fileName + "\" (" + file.length() + " bytes)...");

            try (FileInputStream fileIn = new FileInputStream(file);
                 OutputStream out = socket.getOutputStream()) {

                byte[] buffer = new byte[BUFFER_SIZE];
                int bytesRead;
                long totalSent = 0;

                while ((bytesRead = fileIn.read(buffer)) != -1) {
                    out.write(buffer, 0, bytesRead);
                    totalSent += bytesRead;
                }
                out.flush();
                System.out.println("File transfer complete! Successfully sent " + totalSent + " bytes.");
            }
        } catch (IOException e) {
            System.err.println("File client error: " + e.getMessage());
        }
    }
}
```

--- File 5: CalculatorServer.java (Port 9003) ---
```java
import java.io.*;
import java.net.*;
import java.nio.charset.StandardCharsets;

public class CalculatorServer {
    public static final int PORT = 9003;

    public static void main(String[] args) {
        System.out.println("========================================================");
        System.out.println("  TCP CALCULATOR SERVER LISTENING ON PORT " + PORT + " (JAVA)");
        System.out.println("========================================================");
        System.out.println("Waiting for calculation requests...");

        try (ServerSocket serverSocket = new ServerSocket(PORT)) {
            try (Socket clientSocket = serverSocket.accept()) {
                System.out.println("Client connected from " + clientSocket.getRemoteSocketAddress());

                BufferedReader in = new BufferedReader(
                    new InputStreamReader(clientSocket.getInputStream(), StandardCharsets.UTF_8));
                PrintWriter out = new PrintWriter(
                    new OutputStreamWriter(clientSocket.getOutputStream(), StandardCharsets.UTF_8), true);

                String expr = in.readLine();
                if (expr != null) {
                    System.out.println("Received arithmetic expression: \"" + expr + "\"");

                    String reply = evaluateExpression(expr.trim());
                    System.out.println("Computed reply: \"" + reply + "\"");
                    out.println(reply);
                }
            }
            System.out.println("Calculation finished. Server closed connection.");
        } catch (IOException e) {
            System.err.println("Calculator server error: " + e.getMessage());
        }
    }

    private static String evaluateExpression(String expr) {
        String[] tokens = expr.split("\\s+");
        if (tokens.length != 3) {
            return "Error: Invalid expression format. Expected '<num1> <op> <num2>' (e.g. 15 + 4)";
        }

        try {
            double a = Double.parseDouble(tokens[0]);
            String op = tokens[1];
            double b = Double.parseDouble(tokens[2]);

            switch (op) {
                case "+":
                    return "Result: " + (a + b);
                case "-":
                    return "Result: " + (a - b);
                case "*":
                    return "Result: " + (a * b);
                case "/":
                    if (b == 0) {
                        return "Error: Division by zero is undefined.";
                    }
                    return "Result: " + (a / b);
                default:
                    return "Error: Unsupported operator '" + op + "'. Supported: +, -, *, /";
            }
        } catch (NumberFormatException e) {
            return "Error: Operands must be valid numbers.";
        }
    }
}
```

--- File 6: CalculatorClient.java (Port 9003) ---
```java
import java.io.*;
import java.net.*;
import java.nio.charset.StandardCharsets;
import java.util.Scanner;

public class CalculatorClient {
    public static final int PORT = 9003;

    public static void main(String[] args) {
        String serverIP = args.length > 0 ? args[0] : "127.0.0.1";

        System.out.println("Connecting to TCP Calculator Server at " + serverIP + ":" + PORT + "...");
        try (Socket socket = new Socket(serverIP, PORT);
             Scanner scanner = new Scanner(System.in)) {

            System.out.println("Connected!");

            BufferedReader in = new BufferedReader(
                new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));
            PrintWriter out = new PrintWriter(
                new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8), true);

            System.out.print("Enter arithmetic expression (e.g., 25 + 17 or 100 / 4): ");
            String expr = scanner.hasNextLine() ? scanner.nextLine() : "12 + 7";
            if (expr.trim().isEmpty()) {
                expr = "12 + 7";
            }

            out.println(expr);
            System.out.println("Sent: \"" + expr + "\"");

            String response = in.readLine();
            System.out.println("Server Response: " + response);

        } catch (IOException e) {
            System.err.println("Calculator client error: " + e.getMessage());
        }
    }
}
```

9. EXPLANATION OF THE CODE
--------------------------------------------------------------------------------
- `ServerSocket` vs `Socket`: `ServerSocket` binds to a local port and listens for client connection requests. Calling `accept()` returns a dedicated `Socket` object for communication with the connected client.
- Try-With-Resources: All network sockets and streams are wrapped in try-with-resources statements, guaranteeing sockets and file streams are automatically closed upon exit without resource leaks.
- Character Encoding: Standardizes on `StandardCharsets.UTF_8` to ensure text strings containing special characters are correctly encoded and decoded across operating systems.
- Raw Byte Streaming: `FileServer` and `FileClient` use raw `byte[] buffer = new byte[BUFFER_SIZE]` with `in.read(buffer)` and `fileOut.write(buffer, 0, bytesRead)` to avoid character encodings altering binary data.

15. COMMON ERRORS AND TROUBLESHOOTING
--------------------------------------------------------------------------------
1. `java.net.BindException: Address already in use`: Another program or server instance is using port 9001/9002/9003. Wait a few seconds or terminate the process using `lsof -i :9001`.
2. `java.net.ConnectException: Connection refused`: The server was not started before the client, or the wrong IP address was supplied.

17. VIVA QUESTIONS WITH CONCISE, CORRECT ANSWERS
--------------------------------------------------------------------------------
Q1: What Java class is used to create a TCP server?
A: `java.net.ServerSocket`.

Q2: What Java class is used to create a TCP client?
A: `java.net.Socket`.

Q3: What does the `serverSocket.accept()` method do?
A: It blocks until an incoming client connection request arrives, then returns a new `Socket` object for communication with that client.

Q4: Why should binary files be transferred using `InputStream`/`OutputStream` instead of `Reader`/`Writer`?
A: `Reader`/`Writer` classes interpret byte streams as character text using character encoding mappings (such as UTF-8), which alters and corrupts binary bytes.

Q5: What is the benefit of using try-with-resources in Java networking code?
A: It automatically closes sockets and streams when execution leaves the block, preventing socket handle leaks.

Q6: How does the Java file server detect that the client has finished uploading?
A: The `InputStream.read()` method returns `-1` when the client has reached EOF and closed its output stream/socket.

Q7: What does the boolean `true` parameter in `new PrintWriter(out, true)` signify?
A: It enables auto-flushing, ensuring data is transmitted across the network immediately upon calling `println()`.

Q8: What exception is thrown if the client tries to connect to a host where no server is listening?
A: `java.net.ConnectException: Connection refused`.

Q9: What is the default backlog queue size for `ServerSocket` if unspecified?
A: 50 incoming connection requests.

Q10: Can a Java TCP client communicate with a C++ TCP server?
A: Yes. TCP is a language-agnostic standardized transport protocol; as long as the application-level data format matches, any language can communicate with any other.

Q11: How do you set a socket timeout in Java?
A: Using `socket.setSoTimeout(int milliseconds)`.

Q12: How do you find the client's IP address on the server side?
A: Using `clientSocket.getRemoteSocketAddress()` or `clientSocket.getInetAddress().getHostAddress()`.

Q13: What does `flush()` do on an `OutputStream`?
A: Forces any buffered output bytes to be written out immediately over the underlying network socket.

Q14: What is the OSI layer of TCP sockets?
A: Sockets reside at the Transport Layer (Layer 4) interface presented to the Application Layer (Layer 7).

Q15: How does TCP guarantee reliability?
A: Through sequence numbering, acknowledgment packets, retransmission timers, checksum error detection, and sliding window flow control.
