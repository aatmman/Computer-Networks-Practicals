5. THEORY AND IMPORTANT TERMINOLOGY
--------------------------------------------------------------------------------
- Transmission Control Protocol (TCP): A connection-oriented, reliable transport protocol (Layer 4) providing full-duplex byte-stream delivery between two network endpoints.
- Socket: An endpoint for network communication identified by an IP address and a Port number.
- Three-Way Handshake: Connection establishment sequence before data transfer:
  1. Client sends `SYN` (Synchronize sequence number).
  2. Server responds with `SYN-ACK` (Synchronize and Acknowledge).
  3. Client returns `ACK` (Acknowledge).
- Socket System Calls:
  * `socket(int domain, int type, int protocol)`: Creates an unbound socket endpoint. `AF_INET` specifies IPv4; `SOCK_STREAM` specifies TCP.
  * `bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen)`: Assigns a local IP address and port to the socket.
  * `listen(int sockfd, int backlog)`: Marks the socket as passive to accept incoming connection requests; backlog defines the maximum pending connection queue.
  * `accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen)`: Extracts the first connection request from the queue, creates a new dedicated connected socket descriptor for this client, and returns it.
  * `connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen)`: Initiates the three-way handshake with the server's listening socket.
  * `send()` and `recv()`: Transmit and receive raw byte streams across the established connection.
  * `close()`: Initiates the four-way FIN-ACK connection termination handshake.
- `SO_REUSEADDR`: Socket option that allows immediate rebinding to a port in `TIME_WAIT` state, preventing "Address already in use" errors during testing.

6. WORKING PRINCIPLE / ALGORITHM
--------------------------------------------------------------------------------
Task (a) - Say Hello:
1. Server binds to Port 9001, calls `listen()`, blocks in `accept()`.
2. Client connects to Port 9001, sends `"Hello from TCP Client!"`.
3. Server receives message, prints client IP/port and greeting, and replies with `"Hello from TCP Server!"`.
4. Client prints server's reply and both close their sockets.

Task (b) - File Transfer:
1. Server binds to Port 9002, calls `listen()`, waits in `accept()`.
2. Client connects, opens input file in `ios::binary` mode.
3. Client reads chunks (4096 bytes) and calls `send()` in a loop until EOF.
4. Server reads incoming byte stream via `recv()` and writes chunks directly to `received_file.dat` in `ios::binary` mode.
5. When client finishes and closes its socket, server `recv()` returns 0 (EOF), closing the output file cleanly.

Task (c) - Remote Calculator:
1. Server binds to Port 9003, calls `listen()`, waits in `accept()`.
2. Client prompts user for expression (e.g. `25 + 17`), connects, and sends string.
3. Server receives expression, parses operands and operator using stringstream, computes result or detects errors (such as division by zero), and sends formatted result string back.
4. Client displays the computed result.

```cpp
#include <iostream>
#include <string>
#include <cstring>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

using namespace std;

const int PORT = 9001;

int main() {
    int serverFd = socket(AF_INET, SOCK_STREAM, 0);
    if (serverFd < 0) {
        perror("Socket creation failed");
        return 1;
    }

    int opt = 1;
    setsockopt(serverFd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    sockaddr_in serverAddr{};
    serverAddr.sin_family = AF_INET;
    serverAddr.sin_addr.s_addr = INADDR_ANY;
    serverAddr.sin_port = htons(PORT);

    if (::bind(serverFd, (sockaddr*)&serverAddr, sizeof(serverAddr)) < 0) {
        perror("Bind failed");
        close(serverFd);
        return 1;
    }

    if (listen(serverFd, 5) < 0) {
        perror("Listen failed");
        close(serverFd);
        return 1;
    }

    cout << "========================================================\n";
    cout << "  TCP HELLO SERVER LISTENING ON PORT " << PORT << "\n";
    cout << "========================================================\n";
    cout << "Waiting for incoming client connection...\n";

    sockaddr_in clientAddr{};
    socklen_t clientLen = sizeof(clientAddr);
    int clientFd = accept(serverFd, (sockaddr*)&clientAddr, &clientLen);
    if (clientFd < 0) {
        perror("Accept failed");
        close(serverFd);
        return 1;
    }

    char clientIP[INET_ADDRSTRLEN];
    inet_ntop(AF_INET, &clientAddr.sin_addr, clientIP, sizeof(clientIP));
    cout << "Client connected from " << clientIP << ":" << ntohs(clientAddr.sin_port) << endl;

    char buffer[1024] = {0};
    ssize_t bytesReceived = recv(clientFd, buffer, sizeof(buffer) - 1, 0);
    if (bytesReceived > 0) {
        buffer[bytesReceived] = '\0';
        cout << "Client says: \"" << buffer << "\"" << endl;

        string reply = "Hello from TCP Server! Connection verified.";
        send(clientFd, reply.c_str(), reply.size(), 0);
        cout << "Sent reply: \"" << reply << "\"" << endl;
    }

    close(clientFd);
    close(serverFd);
    cout << "Server closed connection gracefully.\n";
    return 0;
}
```

```cpp
#include <iostream>
#include <string>
#include <cstring>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

using namespace std;

const int PORT = 9001;

int main(int argc, char* argv[]) {
    string serverIP = "127.0.0.1";
    if (argc > 1) {
        serverIP = argv[1];
    }

    int sockFd = socket(AF_INET, SOCK_STREAM, 0);
    if (sockFd < 0) {
        perror("Socket creation failed");
        return 1;
    }

    sockaddr_in serverAddr{};
    serverAddr.sin_family = AF_INET;
    serverAddr.sin_port = htons(PORT);
    if (inet_pton(AF_INET, serverIP.c_str(), &serverAddr.sin_addr) <= 0) {
        cerr << "Invalid address / Address not supported: " << serverIP << endl;
        close(sockFd);
        return 1;
    }

    cout << "Connecting to TCP Hello Server at " << serverIP << ":" << PORT << "..." << endl;
    if (connect(sockFd, (sockaddr*)&serverAddr, sizeof(serverAddr)) < 0) {
        perror("Connection failed");
        close(sockFd);
        return 1;
    }
    cout << "Connected successfully!\n";

    string msg = "Hello from TCP Client! Greetings.";
    send(sockFd, msg.c_str(), msg.size(), 0);
    cout << "Sent message: \"" << msg << "\"" << endl;

    char buffer[1024] = {0};
    ssize_t bytesReceived = recv(sockFd, buffer, sizeof(buffer) - 1, 0);
    if (bytesReceived > 0) {
        buffer[bytesReceived] = '\0';
        cout << "Server replied: \"" << buffer << "\"" << endl;
    }

    close(sockFd);
    cout << "Client closed socket.\n";
    return 0;
}
```

```cpp
#include <iostream>
#include <fstream>
#include <string>
#include <cstring>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

using namespace std;

const int PORT = 9002;
const int BUFFER_SIZE = 4096;

int main() {
    int serverFd = socket(AF_INET, SOCK_STREAM, 0);
    if (serverFd < 0) {
        perror("Socket creation failed");
        return 1;
    }

    int opt = 1;
    setsockopt(serverFd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    sockaddr_in serverAddr{};
    serverAddr.sin_family = AF_INET;
    serverAddr.sin_addr.s_addr = INADDR_ANY;
    serverAddr.sin_port = htons(PORT);

    if (::bind(serverFd, (sockaddr*)&serverAddr, sizeof(serverAddr)) < 0) {
        perror("Bind failed");
        close(serverFd);
        return 1;
    }

    if (listen(serverFd, 5) < 0) {
        perror("Listen failed");
        close(serverFd);
        return 1;
    }

    cout << "========================================================\n";
    cout << "  TCP FILE SERVER LISTENING ON PORT " << PORT << "\n";
    cout << "========================================================\n";
    cout << "Waiting for file upload from client...\n";

    sockaddr_in clientAddr{};
    socklen_t clientLen = sizeof(clientAddr);
    int clientFd = accept(serverFd, (sockaddr*)&clientAddr, &clientLen);
    if (clientFd < 0) {
        perror("Accept failed");
        close(serverFd);
        return 1;
    }

    char clientIP[INET_ADDRSTRLEN];
    inet_ntop(AF_INET, &clientAddr.sin_addr, clientIP, sizeof(clientIP));
    cout << "Client connected from " << clientIP << ":" << ntohs(clientAddr.sin_port) << endl;

    string outputFileName = "received_file.dat";
    ofstream outFile(outputFileName, ios::binary);
    if (!outFile) {
        cerr << "Failed to open destination file for writing.\n";
        close(clientFd);
        close(serverFd);
        return 1;
    }

    char buffer[BUFFER_SIZE];
    ssize_t bytesRead;
    long long totalBytesReceived = 0;

    cout << "Receiving file stream..." << endl;
    while ((bytesRead = recv(clientFd, buffer, sizeof(buffer), 0)) > 0) {
        outFile.write(buffer, bytesRead);
        totalBytesReceived += bytesRead;
    }

    outFile.close();
    cout << "File reception complete! Saved as \"" << outputFileName << "\" (" << totalBytesReceived << " bytes).\n";

    close(clientFd);
    close(serverFd);
    return 0;
}
```

```cpp
#include <iostream>
#include <fstream>
#include <string>
#include <cstring>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

using namespace std;

const int PORT = 9002;
const int BUFFER_SIZE = 4096;

int main(int argc, char* argv[]) {
    string fileName = "send_file.txt";
    string serverIP = "127.0.0.1";

    if (argc > 1) {
        fileName = argv[1];
    }
    if (argc > 2) {
        serverIP = argv[2];
    }

    ifstream inFile(fileName, ios::binary);
    if (!inFile) {
        // Create a default sample file if none exists
        ofstream sample(fileName);
        sample << "This is sample text transmitted over a reliable TCP socket byte stream.\n";
        sample << "TCP guarantees error-checked in-order delivery of all transmitted bytes.\n";
        sample.close();
        inFile.open(fileName, ios::binary);
        cout << "Created default sample file: \"" << fileName << "\"\n";
    }

    int sockFd = socket(AF_INET, SOCK_STREAM, 0);
    if (sockFd < 0) {
        perror("Socket creation failed");
        return 1;
    }

    sockaddr_in serverAddr{};
    serverAddr.sin_family = AF_INET;
    serverAddr.sin_port = htons(PORT);
    if (inet_pton(AF_INET, serverIP.c_str(), &serverAddr.sin_addr) <= 0) {
        cerr << "Invalid address: " << serverIP << endl;
        close(sockFd);
        return 1;
    }

    cout << "Connecting to TCP File Server at " << serverIP << ":" << PORT << "..." << endl;
    if (connect(sockFd, (sockaddr*)&serverAddr, sizeof(serverAddr)) < 0) {
        perror("Connection failed");
        close(sockFd);
        return 1;
    }
    cout << "Connected! Sending file: \"" << fileName << "\"...\n";

    char buffer[BUFFER_SIZE];
    long long totalBytesSent = 0;

    while (inFile.read(buffer, sizeof(buffer)) || inFile.gcount() > 0) {
        streamsize bytesToSend = inFile.gcount();
        ssize_t bytesSent = send(sockFd, buffer, bytesToSend, 0);
        if (bytesSent < 0) {
            perror("Send failed");
            break;
        }
        totalBytesSent += bytesSent;
    }

    inFile.close();
    cout << "File transfer complete! Successfully sent " << totalBytesSent << " bytes.\n";

    close(sockFd);
    return 0;
}
```

```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <cstring>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

using namespace std;

const int PORT = 9003;

int main() {
    int serverFd = socket(AF_INET, SOCK_STREAM, 0);
    if (serverFd < 0) {
        perror("Socket creation failed");
        return 1;
    }

    int opt = 1;
    setsockopt(serverFd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    sockaddr_in serverAddr{};
    serverAddr.sin_family = AF_INET;
    serverAddr.sin_addr.s_addr = INADDR_ANY;
    serverAddr.sin_port = htons(PORT);

    if (::bind(serverFd, (sockaddr*)&serverAddr, sizeof(serverAddr)) < 0) {
        perror("Bind failed");
        close(serverFd);
        return 1;
    }

    if (listen(serverFd, 5) < 0) {
        perror("Listen failed");
        close(serverFd);
        return 1;
    }

    cout << "========================================================\n";
    cout << "  TCP CALCULATOR SERVER LISTENING ON PORT " << PORT << "\n";
    cout << "========================================================\n";
    cout << "Waiting for calculation requests...\n";

    sockaddr_in clientAddr{};
    socklen_t clientLen = sizeof(clientAddr);
    int clientFd = accept(serverFd, (sockaddr*)&clientAddr, &clientLen);
    if (clientFd < 0) {
        perror("Accept failed");
        close(serverFd);
        return 1;
    }

    char buffer[512] = {0};
    ssize_t bytesReceived = recv(clientFd, buffer, sizeof(buffer) - 1, 0);
    if (bytesReceived > 0) {
        buffer[bytesReceived] = '\0';
        cout << "Received arithmetic expression: \"" << buffer << "\"" << endl;

        double a, b;
        char op;
        istringstream iss(buffer);
        string reply;

        if (iss >> a >> op >> b) {
            double result = 0;
            bool valid = true;
            switch (op) {
                case '+': result = a + b; break;
                case '-': result = a - b; break;
                case '*': result = a * b; break;
                case '/':
                    if (b != 0) {
                        result = a / b;
                    } else {
                        valid = false;
                        reply = "Error: Division by zero is undefined.";
                    }
                    break;
                default:
                    valid = false;
                    reply = "Error: Unsupported operator '" + string(1, op) + "'. Supported: +, -, *, /";
            }
            if (valid) {
                reply = "Result: " + to_string(result);
            }
        } else {
            reply = "Error: Invalid expression format. Expected '<num1> <op> <num2>' (e.g. 15 + 4)";
        }

        cout << "Computed reply: \"" << reply << "\"" << endl;
        send(clientFd, reply.c_str(), reply.size(), 0);
    }

    close(clientFd);
    close(serverFd);
    cout << "Calculation finished. Server closed connection.\n";
    return 0;
}
```

15. COMMON ERRORS AND TROUBLESHOOTING
--------------------------------------------------------------------------------
1. `Connection refused`: The client was started before the server, or the server is bound to a different port. Start server first.
2. `Address already in use`: A previous server instance did not release the port. Fixed in our code via `SO_REUSEADDR`.
3. Firewall blocks: When running across two physical machines, ensure inbound TCP ports 9001, 9002, and 9003 are permitted through local firewalls (`ufw allow 9001:9003/tcp`).

17. VIVA QUESTIONS WITH CONCISE, CORRECT ANSWERS
--------------------------------------------------------------------------------
Q1: What are the main characteristics of TCP?
A: Connection-oriented, reliable, byte-stream, full-duplex, point-to-point, flow-controlled, and congestion-controlled.

Q2: What is the sequence of socket system calls for a TCP server?
A: `socket()` -> `bind()` -> `listen()` -> `accept()` -> `recv()`/`send()` -> `close()`.

Q3: What is the sequence of socket system calls for a TCP client?
A: `socket()` -> `connect()` -> `send()`/`recv()` -> `close()`.

Q4: What is the purpose of the `listen()` call?
A: It puts the socket in passive listening mode and sets the backlog queue length for incoming connections.

Q5: What does the `accept()` call return?
A: A brand new connected socket descriptor dedicated to communication with that specific client, leaving the original listening socket free to accept further connections.

Q6: What is the TCP 3-way handshake?
A: SYN (client to server) -> SYN-ACK (server to client) -> ACK (client to server).

Q7: What is the TCP 4-way termination handshake?
A: FIN -> ACK -> FIN -> ACK.

Q8: What does `htons()` do?
A: "Host TO Network Short"; converts a 16-bit integer from host byte order (typically little-endian) to network byte order (big-endian).

Q9: What does `inet_pton()` do?
A: Converts an IP address from presentation (text string) to network (binary) format.

Q10: Why is TCP suitable for file transfer?
A: TCP guarantees in-order, error-checked, duplicate-free delivery with automatic retransmissions, guaranteeing the received file is byte-for-byte identical to the original.

Q11: What does `recv()` return when the peer has closed the connection cleanly?
A: It returns 0 (EOF signal in stream sockets).

Q12: What does a negative return value from `recv()` or `send()` signify?
A: An error occurred; check `errno` or use `perror()` for the diagnostic description.

Q13: Why is `SO_REUSEADDR` important in socket programming?
A: It allows the socket to rebind to a local port that is currently in the `TIME_WAIT` state from a recent closure.

Q14: How does the file server know when the file transfer is complete?
A: When the client finishes sending and closes its socket, the server's `recv()` call returns 0, terminating the receive loop.

Q15: What would happen if the calculator client sends division by zero without server validation?
A: Without validation, floating-point division produces `inf` or causes a hardware exception; our code validates `b != 0` and returns an explicit error string.
