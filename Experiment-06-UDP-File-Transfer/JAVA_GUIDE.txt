5. THEORY AND IMPORTANT TERMINOLOGY
--------------------------------------------------------------------------------
- User Datagram Protocol (UDP, RFC 768): A lightweight, connectionless transport protocol providing direct access to the datagram model of the IP layer. Minimal header overhead (8 bytes compared to TCP's 20-60 bytes).
- Java UDP Abstractions:
  * `DatagramSocket`: Represents a socket for sending and receiving datagram packets. Can be bound to a specific local port for receiving, or assigned an ephemeral port for sending.
  * `DatagramPacket`: Represents a datagram packet containing the payload byte array, packet length, and the destination IP and port address.
  * `InetAddress`: Encapsulates an IP address (IPv4 or IPv6), resolved using `InetAddress.getByName()`.
- UDP vs TCP:
  * TCP establishes a virtual connection via a three-way handshake and handles acknowledgments, retransmissions, and ordering automatically.
  * UDP sends independent datagrams. If an intermediate network buffer or receiver kernel buffer overflows, packets are dropped silently without notification.
- Chunking & Pacing:
  * Chunking splits large files into standard buffers (1024 bytes).
  * Pacing delays (`Thread.sleep(1)`) prevent the sender thread from monopolizing the CPU and overwhelming the receiver's socket receive buffer.
- EOF Detection: An application-level token (`<<EOF>>`) is transmitted to tell the receiver's receive loop when to break.

6. WORKING PRINCIPLE / ALGORITHM
--------------------------------------------------------------------------------
Receiver (Server):
1. Instantiate `DatagramSocket(9100)`.
2. Open destination file using `FileOutputStream(outputFilename)`.
3. Allocate byte buffer `byte[1024]` and create `DatagramPacket(buffer, buffer.length)`.
4. Loop calling `socket.receive(packet)`:
   - Extract string payload to check if it equals `<<EOF>>`.
   - If marker detected, break receive loop.
   - Otherwise, write raw bytes: `fileOut.write(packet.getData(), 0, packet.getLength())`.
5. Close file and socket; print total bytes and chunks received.

Sender (Client):
1. Open source file using `FileInputStream(file)`.
2. Instantiate unbound `DatagramSocket()`.
3. Resolve destination IP via `InetAddress.getByName(receiverIP)`.
4. Loop reading 1024-byte chunks from file:
   - Construct `DatagramPacket(buffer, bytesRead, receiverAddress, 9100)`.
   - Call `socket.send(packet)`.
   - Apply `Thread.sleep(1)` pacing delay.
5. After file loop terminates, send `<<EOF>>` marker packet 3 times with short pauses.
6. Close file and socket; print total bytes sent.

8. COMPLETE SOURCE CODE (JAVA)
--------------------------------------------------------------------------------
All source files are located in `Experiment-06-UDP-File-Transfer/java/`:

--- File 1: UDPFileReceiver.java ---
```java
import java.io.*;
import java.net.*;
import java.nio.charset.StandardCharsets;

public class UDPFileReceiver {
    public static final int PORT = 9100;
    public static final int CHUNK_SIZE = 1024;
    public static final String END_MARKER = "<<EOF>>";

    public static void main(String[] args) {
        String outputFilename = args.length > 0 ? args[0] : "received_output";

        System.out.println("========================================================");
        System.out.println("  UDP FILE RECEIVER LISTENING ON PORT " + PORT + " (JAVA)");
        System.out.println("========================================================");
        System.out.println("Output will be saved to: \"" + outputFilename + "\"");
        System.out.println("Waiting for incoming datagrams...");

        try (DatagramSocket socket = new DatagramSocket(PORT);
             FileOutputStream fileOut = new FileOutputStream(outputFilename)) {

            byte[] buffer = new byte[CHUNK_SIZE];
            DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
            long totalBytes = 0;
            int chunkCount = 0;

            while (true) {
                socket.receive(packet);
                int length = packet.getLength();

                // Check for EOF marker
                String markerCheck = new String(packet.getData(), 0, length, StandardCharsets.UTF_8);
                if (markerCheck.equals(END_MARKER)) {
                    System.out.println("\n[EOF Marker Received] File transfer complete.");
                    break;
                }

                fileOut.write(packet.getData(), 0, length);
                totalBytes += length;
                chunkCount++;

                if (chunkCount % 50 == 0) {
                    System.out.print(".");
                }
            }

            System.out.println("Received from " + packet.getAddress() + ":" + packet.getPort());
            System.out.println("Total Chunks Received: " + chunkCount);
            System.out.println("Total Bytes Saved    : " + totalBytes + " bytes");

        } catch (IOException e) {
            System.err.println("Receiver error: " + e.getMessage());
        }
    }
}
```

--- File 2: UDPFileSender.java ---
```java
import java.io.*;
import java.net.*;
import java.nio.charset.StandardCharsets;

public class UDPFileSender {
    public static final int PORT = 9100;
    public static final int CHUNK_SIZE = 1024;
    public static final String END_MARKER = "<<EOF>>";

    public static void main(String[] args) {
        if (args.length < 1) {
            System.out.println("Usage: java UDPFileSender <filename> [receiver_ip]");
            return;
        }

        String fileName = args[0];
        String receiverIP = args.length > 1 ? args[1] : "127.0.0.1";

        File file = new File(fileName);
        if (!file.exists()) {
            try (FileWriter fw = new FileWriter(file)) {
                fw.write("#!/usr/bin/env python3\n# Transferred over Java UDP DatagramSocket\nprint('UDP transfer successful!')\n");
            } catch (IOException e) {
                System.err.println("Could not create sample file: " + e.getMessage());
            }
            System.out.println("Created default sample file: \"" + fileName + "\"");
        }

        System.out.println("========================================================");
        System.out.println("  UDP FILE SENDER -> " + receiverIP + ":" + PORT + " (JAVA)");
        System.out.println("========================================================");
        System.out.println("Sending file: \"" + fileName + "\" (" + file.length() + " bytes)...");

        try (DatagramSocket socket = new DatagramSocket();
             FileInputStream fileIn = new FileInputStream(file)) {

            InetAddress receiverAddress = InetAddress.getByName(receiverIP);
            byte[] buffer = new byte[CHUNK_SIZE];
            int bytesRead;
            long totalBytes = 0;
            int chunkCount = 0;

            while ((bytesRead = fileIn.read(buffer)) != -1) {
                DatagramPacket packet = new DatagramPacket(buffer, bytesRead, receiverAddress, PORT);
                socket.send(packet);
                totalBytes += bytesRead;
                chunkCount++;

                // Pacing delay to prevent buffer overruns on fast loops
                try {
                    Thread.sleep(1);
                } catch (InterruptedException ignored) {}

                if (chunkCount % 50 == 0) {
                    System.out.print(".");
                }
            }

            // Send EOF marker (repeat 3 times with brief pauses)
            byte[] eofBytes = END_MARKER.getBytes(StandardCharsets.UTF_8);
            for (int k = 0; k < 3; k++) {
                DatagramPacket eofPacket = new DatagramPacket(eofBytes, eofBytes.length, receiverAddress, PORT);
                socket.send(eofPacket);
                try { Thread.sleep(5); } catch (InterruptedException ignored) {}
            }

            System.out.println("\nFile transfer finished successfully!");
            System.out.println("Total Chunks Sent : " + chunkCount);
            System.out.println("Total Bytes Sent  : " + totalBytes + " bytes");

        } catch (IOException e) {
            System.err.println("Sender error: " + e.getMessage());
        }
    }
}
```

9. EXPLANATION OF THE CODE
--------------------------------------------------------------------------------
- `DatagramSocket`: Instantiated with port 9100 on the receiver to listen for incoming UDP packets, and with no arguments on the sender to bind an ephemeral client port.
- `DatagramPacket`: Bundles the raw binary chunk data (`buffer`), length (`bytesRead`), destination address (`receiverAddress`), and port (`PORT`).
- Binary Streams: `FileInputStream` and `FileOutputStream` read and write exact bytes without UTF-8 character mutations, ensuring scripts, binary images, audio, and video files are preserved intact.
- EOF Marker: Strings are encoded to UTF-8 bytes to transmit `<<EOF>>`. When the receiver detects this string, it terminates its receive loop.
- Redundant Transmission: The sender repeats the EOF packet 3 times (`for (int k = 0; k < 3; k++)`) to protect against single-packet loss over lossy UDP links.
- `Thread.sleep(1)`: Pacing delay between datagram sends to allow the operating system's receive buffer to drain and prevent drops.

15. COMMON ERRORS AND TROUBLESHOOTING
--------------------------------------------------------------------------------
1. `java.net.BindException: Address already in use`: Another program is using port 9100. Check with `lsof -i :9100`.
2. Silent packet drops: If transferring a large video or audio file on a real network, omission of `Thread.sleep(1)` can drop chunks. Keep pacing enabled.

16. MANUAL CODE NOTE / CORRECTION / ENHANCEMENT
--------------------------------------------------------------------------------
- UDP Reliability Note: Raw UDP offers no reliability guarantees. This program illustrates connectionless chunked transfer. In real-world enterprise UDP applications, custom sequence numbering and retransmission logic (e.g. TFTP/QUIC) must be added if reliability is required.
- Added triple-transmission of the `<<EOF>>` marker to prevent the receiver hanging if a single UDP packet is dropped.

17. VIVA QUESTIONS WITH CONCISE, CORRECT ANSWERS
--------------------------------------------------------------------------------
Q1: What Java classes are used for UDP socket programming?
A: `java.net.DatagramSocket` and `java.net.DatagramPacket`.

Q2: What is the main difference between `Socket` and `DatagramSocket` in Java?
A: `Socket` provides a reliable TCP stream; `DatagramSocket` transmits independent, connectionless UDP packets.

Q3: Does `DatagramSocket` require a handshake before sending data?
A: No. Senders construct a `DatagramPacket` with the target IP/port and call `send()` immediately.

Q4: What happens if `DatagramSocket.receive()` is called and no packet has arrived?
A: The thread blocks until a datagram arrives, unless a timeout has been configured via `setSoTimeout()`.

Q5: How is the sender's address determined on the receiving side in Java?
A: By calling `packet.getAddress()` and `packet.getPort()` on the received `DatagramPacket`.

Q6: Why is binary mode (`FileInputStream`/`FileOutputStream`) mandatory for generic file transfer?
A: To prevent character encoders from altering binary bytes found in compiled scripts, audio, and video formats.

Q7: What is the maximum payload size of a standard IPv4 UDP datagram?
A: 65,507 bytes (65,535 bytes total IP length - 20 bytes IP header - 8 bytes UDP header).

Q8: Why are 1024-byte chunks chosen instead of the maximum 65,507 bytes?
A: To avoid IP-level fragmentation, keeping packets within the Ethernet MTU (1500 bytes).

Q9: What causes packet loss during high-speed local UDP transfer?
A: Socket buffer overruns (`SO_RCVBUF`) when the sender sends datagrams faster than the receiver thread can drain them.

Q10: What does `Thread.sleep(1)` achieve in the sender loop?
A: Transmission pacing; it throttles dispatch to match the kernel's receive buffer processing rate.

Q11: How does Java handle IP address resolution for UDP?
A: Using `InetAddress.getByName(hostString)`, which performs DNS or hosts-file lookup.

Q12: Is UDP header larger or smaller than TCP?
A: Much smaller: 8 bytes for UDP versus 20 to 60 bytes for TCP.

Q13: Can a Java UDP sender transmit to a C++ UDP receiver?
A: Yes. UDP datagrams follow the RFC 768 wire standard, which is completely language-agnostic.

Q14: What is the risk of using an application EOF marker over UDP?
A: If the EOF packet is dropped by the network, the receiver remains blocked waiting for further packets.

Q15: How can EOF detection be made reliable over UDP?
A: By retransmitting the marker multiple times, using timeouts with `setSoTimeout()`, or requiring the receiver to return an ACK.
