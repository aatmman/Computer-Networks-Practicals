5. THEORY AND IMPORTANT TERMINOLOGY
--------------------------------------------------------------------------------
- Sliding Window Protocol: A flow control and reliable transmission technique that allows the sender to transmit multiple data frames (up to window size N) without waiting for an acknowledgment (ACK) for each individual frame, overcoming the low throughput of Stop-and-Wait.
- Sender Window: The range of consecutive sequence numbers that the sender is authorized to transmit without receiving an ACK. As acknowledgments arrive, the window "slides" forward over higher sequence numbers.
- Go-Back-N (GBN) ARQ:
  * Cumulative Acknowledgments: An ACK for frame n (ACK n) implies all frames up to and including n have been successfully received.
  * Receiver Window Size = 1: The receiver accepts frames only in strict sequential order. If an out-of-order frame arrives (due to a preceding lost or damaged frame), the receiver discards it immediately without buffering.
  * Retransmission: On sender timeout for frame k, the sender must roll back and retransmit frame k and ALL subsequent frames currently outstanding in the window, even if those subsequent frames originally reached the receiver intact.
- Selective Repeat (SR) ARQ:
  * Individual Acknowledgments: Each frame is acknowledged individually.
  * Receiver Window Size = N: The receiver possesses an internal buffer capable of storing up to N out-of-order but uncorrupted frames.
  * Retransmission: On sender timeout for frame k, the sender retransmits ONLY frame k. Correctly received out-of-order frames are retained in the receiver's buffer, avoiding redundant retransmissions.
- Sequence Number Constraints:
  * If sequence numbers use m bits (range 0 to 2^m - 1):
  * GBN maximum window size is 2^m - 1 to prevent ambiguity between duplicate ACKs of consecutive cycles.
  * SR maximum window size is 2^(m - 1) to ensure the sender window and receiver window never overlap across modular sequence numbering cycles.

6. WORKING PRINCIPLE / ALGORITHM
--------------------------------------------------------------------------------
Go-Back-N Algorithm:
1. Initialize `base = 0`, `windowSize = N`, `totalFrames = M`.
2. While `base < totalFrames`:
   a. Compute active window bounds: `[base .. Math.min(base + N, totalFrames) - 1]`.
   b. Transmit all frames in the window.
   c. If a frame `lostFrame` within the window is simulated as lost:
      - The receiver receives and drops `lostFrame`.
      - For all subsequent frames in this window pass, the receiver discards them as out-of-order.
      - Sender timer expires for `lostFrame`.
      - Count retransmissions: `retransmissions += (windowEnd - lostFrame)`.
      - Roll back sender `base` to `lostFrame`.
      - Mark loss handled (`lostFrame = -1`) so the next pass delivers cleanly.
   d. If no loss in the window:
      - All frames acknowledged cumulatively.
      - Slide window forward: `base = windowEnd`.

Selective Repeat Algorithm:
1. Initialize `base = 0`, boolean arrays `acked[totalFrames]` and `receiverBuffered[totalFrames]`.
2. While `base < totalFrames`:
   a. Compute active window bounds: `[base .. Math.min(base + N, totalFrames) - 1]`.
   b. Transmit all unacknowledged frames in the window.
   c. If a frame `lostFrame` within the window is dropped:
      - Frames arriving after `lostFrame` are buffered by the receiver and individually acknowledged (`acked[i] = true`).
      - Sender timer expires solely for `lostFrame`.
      - Retransmit ONLY `lostFrame`: `retransmissions += 1`.
      - Mark `acked[lostFrame] = true` and `lostFrame = -1`.
   d. Slide window forward: advance `base` past all consecutively acknowledged frames.

```java
import java.util.Scanner;

public class GoBackN {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("========================================================");
        System.out.println("    GO-BACK-N (GBN) SLIDING WINDOW ARQ SIMULATION - JAVA");
        System.out.println("========================================================");

        System.out.print("Enter total number of frames to send: ");
        int totalFrames = scanner.nextInt();
        if (totalFrames <= 0) {
            System.err.println("Error: Total frames must be a positive integer.");
            scanner.close();
            return;
        }

        System.out.print("Enter sliding window size (N): ");
        int windowSize = scanner.nextInt();
        if (windowSize <= 0) {
            System.err.println("Error: Window size must be a positive integer.");
            scanner.close();
            return;
        }

        System.out.print("Enter frame index to simulate as LOST (0-indexed, or -1 for none): ");
        int lostFrame = scanner.nextInt();

        int base = 0;
        int retransmissions = 0;
        int passNumber = 1;

        System.out.println("\nStarting Go-Back-N Simulation...");
        System.out.println("Window Size (N) = " + windowSize + ", Total Frames = " + totalFrames);

        while (base < totalFrames) {
            int windowEnd = Math.min(base + windowSize, totalFrames);
            System.out.println("\n[Pass " + (passNumber++) + "] Active Window: [" + base + " .. " + (windowEnd - 1) + "]");
            System.out.println("  Sender transmitting frames " + base + " through " + (windowEnd - 1) + "...");

            boolean lossOccurred = false;
            int firstLostInThisPass = -1;

            for (int i = base; i < windowEnd; i++) {
                if (i == lostFrame) {
                    System.out.println("    -> Frame " + i + " : [DROPPED / LOST IN TRANSIT]");
                    lossOccurred = true;
                    firstLostInThisPass = i;
                    // In Go-Back-N, receiver discards all subsequent out-of-order frames
                    for (int j = i + 1; j < windowEnd; j++) {
                        System.out.println("    -> Frame " + j + " : [ARRIVED OUT-OF-ORDER - DISCARDED BY RECEIVER]");
                    }
                    break;
                } else {
                    System.out.println("    -> Frame " + i + " : [RECEIVED & CUMULATIVE ACK SENT]");
                }
            }

            if (lossOccurred) {
                System.out.println("  [TIMEOUT] Timer expired for unacknowledged Frame " + firstLostInThisPass + "!");
                System.out.println("  [GO-BACK-N ACTION] Sender rolls window back to Frame " + firstLostInThisPass + ".");
                int framesToRetransmit = windowEnd - firstLostInThisPass;
                System.out.print("  Retransmitting " + framesToRetransmit + " frame(s): ");
                for (int r = firstLostInThisPass; r < windowEnd; r++) {
                    System.out.print(r + (r == windowEnd - 1 ? "" : ", "));
                }
                System.out.println();
                retransmissions += framesToRetransmit;

                // Reset lostFrame so it successfully delivers upon retransmission
                lostFrame = -1;
                // Roll back sender base to the lost frame
                base = firstLostInThisPass;
            } else {
                System.out.println("  All frames in window [" + base + " .. " + (windowEnd - 1) + "] acknowledged successfully.");
                base = windowEnd; // Slide window forward
            }
        }

        System.out.println("\n========================================================");
        System.out.println("SIMULATION COMPLETE");
        System.out.println("Total Frames Successfully Transmitted : " + totalFrames);
        System.out.println("Total Retransmissions in Go-Back-N     : " + retransmissions);
        System.out.println("Total Frame Transmissions (Original+Retx): " + (totalFrames + retransmissions));
        System.out.println("========================================================");

        scanner.close();
    }
}
```

--- File: SelectiveRepeat.java ---
```java
import java.util.Scanner;

public class SelectiveRepeat {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("========================================================");
        System.out.println("  SELECTIVE REPEAT (SR) SLIDING WINDOW ARQ SIMULATION - JAVA");
        System.out.println("========================================================");

        System.out.print("Enter total number of frames to send: ");
        int totalFrames = scanner.nextInt();
        if (totalFrames <= 0) {
            System.err.println("Error: Total frames must be a positive integer.");
            scanner.close();
            return;
        }

        System.out.print("Enter sliding window size (N): ");
        int windowSize = scanner.nextInt();
        if (windowSize <= 0) {
            System.err.println("Error: Window size must be a positive integer.");
            scanner.close();
            return;
        }

        System.out.print("Enter frame index to simulate as LOST (0-indexed, or -1 for none): ");
        int lostFrame = scanner.nextInt();

        boolean[] acked = new boolean[totalFrames];
        boolean[] receiverBuffered = new boolean[totalFrames];
        int retransmissions = 0;
        int base = 0;
        int passNumber = 1;

        System.out.println("\nStarting Selective Repeat Simulation...");
        System.out.println("Window Size (N) = " + windowSize + ", Total Frames = " + totalFrames);

        while (base < totalFrames) {
            int windowEnd = Math.min(base + windowSize, totalFrames);
            System.out.println("\n[Pass " + (passNumber++) + "] Active Window: [" + base + " .. " + (windowEnd - 1) + "]");
            System.out.println("  Sender transmitting unacknowledged frames in window...");

            boolean lossOccurred = false;

            for (int i = base; i < windowEnd; i++) {
                if (acked[i]) {
                    System.out.println("    -> Frame " + i + " : [ALREADY ACKNOWLEDGED - SKIPPED]");
                    continue;
                }

                if (i == lostFrame) {
                    System.out.println("    -> Frame " + i + " : [DROPPED / LOST IN TRANSIT]");
                    lossOccurred = true;
                } else {
                    acked[i] = true;
                    receiverBuffered[i] = true;
                    System.out.println("    -> Frame " + i + " : [RECEIVED & BUFFERED OUT-OF-ORDER BY RECEIVER -> INDIVIDUAL ACK SENT]");
                }
            }

            if (lossOccurred) {
                System.out.println("  [TIMEOUT] Timer expired ONLY for unacknowledged Frame " + lostFrame + "!");
                System.out.println("  [SELECTIVE REPEAT ACTION] Retransmitting ONLY Frame " + lostFrame + "...");
                System.out.println("    -> Frame " + lostFrame + " : [RETRANSMITTED SUCCESSFULLY -> ACK RECEIVED]");
                acked[lostFrame] = true;
                receiverBuffered[lostFrame] = true;
                retransmissions++;
                lostFrame = -1; // Loss handled
            }

            // Slide window forward past all consecutively acknowledged frames
            int oldBase = base;
            while (base < totalFrames && acked[base]) {
                base++;
            }
            System.out.println("  Receiver delivered in-order frames up to " + (base - 1) + ".");
            System.out.println("  Window slid forward by " + (base - oldBase) + " position(s). New base = " + base);
        }

        System.out.println("\n========================================================");
        System.out.println("SIMULATION COMPLETE");
        System.out.println("Total Frames Successfully Transmitted : " + totalFrames);
        System.out.println("Total Retransmissions in Selective Repeat : " + retransmissions);
        System.out.println("Total Frame Transmissions (Original+Retx): " + (totalFrames + retransmissions));
        System.out.println("========================================================");

        scanner.close();
    }
}
```

9. EXPLANATION OF THE CODE
--------------------------------------------------------------------------------
- Public Classes: File names `GoBackN.java` and `SelectiveRepeat.java` correspond to their respective public class names.
- In `GoBackN`:
  * Simulates receiver window = 1.
  * When frame `lostFrame` fails, all following frames in the pass are explicitly dropped and discarded.
  * Sender rolls back `base = firstLostInThisPass` and retransmits all `(windowEnd - firstLostInThisPass)` frames.
- In `SelectiveRepeat`:
  * Simulates receiver window = N using boolean arrays `acked` and `receiverBuffered`.
  * Out-of-order frames that succeed are marked ACKed and buffered.
  * When timeout occurs, only `lostFrame` is retransmitted (`retransmissions++`).
  * Once `lostFrame` is ACKed, the receiver delivers all buffered frames in order and slides the window forward (`base++`).

17. VIVA QUESTIONS WITH CONCISE, CORRECT ANSWERS
--------------------------------------------------------------------------------
Q1: What is the purpose of the sliding window mechanism?
A: To enable continuous transmission of multiple frames up to window size N without stopping for an ACK after every frame, maximizing link throughput.

Q2: What is the receiver window size in Go-Back-N?
A: 1. It only accepts the single frame matching its expected sequence number.

Q3: What is the receiver window size in Selective Repeat?
A: N (equal to the sender window size), allowing buffering of up to N out-of-order frames.

Q4: What is a cumulative acknowledgment?
A: An acknowledgment that confirms receipt of all consecutive frames up to a specified sequence number.

Q5: What is an individual acknowledgment?
A: An acknowledgment that confirms receipt of a specific individual frame regardless of preceding frames.

Q6: In Go-Back-N, what does the receiver do with correctly received out-of-order frames?
A: It immediately discards them.

Q7: What is the maximum window size in Go-Back-N for m-bit sequence numbers?
A: 2^m - 1.

Q8: What is the maximum window size in Selective Repeat for m-bit sequence numbers?
A: 2^(m - 1).

Q9: Why is the maximum window size in Selective Repeat limited to 2^(m - 1)?
A: To prevent overlapping between the receiver window and the next sequence number cycle, which would cause retransmitted old frames to be misinterpreted as new frames.

Q10: Which protocol requires more complex buffer management at the receiver?
A: Selective Repeat, because it must store, sort, and reassemble out-of-order frames.

Q11: How does Go-Back-N handle the loss of an intermediate ACK?
A: If a subsequent ACK arrives before the timer expires, the earlier loss is ignored because of cumulative ACKs.

Q12: Why is Selective Repeat preferred over high-latency noisy channels?
A: Because retransmitting only the lost frame saves significant bandwidth compared to retransmitting the entire window.

Q13: What happens on a timeout in Go-Back-N?
A: The sender rolls back its window pointer and retransmits all frames from the timed-out frame up to the end of the current window.

Q14: How does TCP incorporate sliding window concepts?
A: TCP uses a byte-oriented sliding window with cumulative ACKs and selective acknowledgment (SACK) options.

Q15: What is Stop-and-Wait ARQ in relation to sliding window?
A: Stop-and-Wait is a special case of sliding window where the sender window size N = 1 and receiver window size = 1.

In Go-Back-N, because the receiver window is 1, any frame arriving after a lost frame is discarded, requiring the sender to retransmit the lost frame and all subsequent frames in the window upon timeout. In Selective Repeat, the receiver has a window size equal to N and buffers out-of-order frames, returning individual ACKs. 19. QUICK REVISION POINTS
--------------------------------------------------------------------------------
- GBN: Receiver window = 1; cumulative ACK; discards out-of-order; retransmits N frames; Max N = 2^m - 1.
- SR: Receiver window = N; individual ACK; buffers out-of-order; retransmits 1 frame; Max N = 2^(m - 1).
- Efficiency: SR uses fewer retransmissions and less bandwidth over noisy links.
- Complexity: SR requires receiver sorting/buffering and per-frame timers.
